# HUMAIRE: Human-First Ethical AI Platform

**HUMAIRE** is a human-centered AI platform designed to promote ethical communication, digital safety, and inclusive opportunities in the world of jobs and internships.

In a digital space where bias, harmful language, and unfair filtering can silently block people’s chances, HUMAIRE puts the human back at the center.

## 🚀 Mission

To create a safer, fairer, and more humane digital future by empowering users with ethical AI tools that foster dignity and equal opportunity.

## ✨ Core Features

*   **🛡️ Bias Detection & Safety**: Analyzes CVs and job/internship postings to detect offensive, biased, or risky language.
*   **🧠 Ethical Explanations**: Clearly explains *why* certain language is problematic, fostering understanding rather than just correction.
*   **✍️ Inclusive Rewrites**: Suggests ethical, inclusive alternatives while preserving the original message's intent.
*   **🎓 Reflection & Learning**: Empowers users to reflect on their communication style, helping them learn professional and respectful discourse.
*   **🤝 Fair Matching**: Intelligently matches users with relevant opportunities based on skills and values, not demographics.
*   **📝 Ethical Application Generation**: Generates ethical application text with full user control.

## 💎 Core Values

1.  **Human Dignity**: Respecting the individual behind every data point.
2.  **Ethical AI**: Technology that serves humanity, not the other way around.
3.  **Equal Opportunity**: Leveling the playing field for all candidates.

## 🚦 Getting Started

### Prerequisites

*   Node.js (v16+)
*   MongoDB

### Installation

1.  **Clone the repository**
2.  **Install Frontend Dependencies**
    ```bash
    cd frontend
    npm install
    ```
3.  **Install Backend Dependencies**
    ```bash
    cd backend
    npm install
    ```

### Running the App

1.  **Start Backend**
    ```bash
    cd backend
    npm run dev
    ```
2.  **Start Frontend**
    ```bash
    cd frontend
    npm run dev
    ```
